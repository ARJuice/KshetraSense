# Research Notes & Technical Foundations

This directory contains research papers, technical evaluations, integration audits, and scientific evidence reviews that establish the agronomic and computational foundation of **KshetraSense**.

---

## Research Papers & Notes Index

| Document | Subject Area | Primary Findings & Focus |
|---|---|---|
| [**Crop Fit Crop Selection**](crop-fit-crop-selection.md) | Agronomic Catalog | Sourced basis for regional Karnataka cultivars (Finger Millet / Ragi, Tomato, Groundnut) using UAS Bengaluru and ICAR research; rationale for uniform -0.10 pH demonstration offset. |
| [**Crop Suitability Probability**](crop-suitability-probability.md) | Agronomic Mathematics | Methodological analysis of why single-season soil tests cannot yield valid Bayesian or frequentist cultivation probabilities, and why unnormalized factor intervals are required. |
| [**CropSight & SoilGrids Architecture**](cropsight-soilgrids-integration-architecture.md) | Remote Sensing & WCS | Deep architectural audit of Sentinel-2 NDVI processing in CropSight, upstream code limitations, and clean decoupling from the host application. |
| [**Open-Source AgTech Overview**](farmos-soilgrids-pyaez-cropsight-technical-overview.md) | Systems Review | In-depth technical review of farmOS, SoilGrids 2.0, PyAEZ (FAO-IIASA), and CropSight implementations, data contracts, and license evaluations. |
| [**Open-Source Architecture Landscape**](open-source-architecture-landscape.md) | Ecosystem Analysis | Comparative analysis of spatial precision agriculture systems, geospatial data formats (GeoJSON, GeoTIFF, WCS), and local-first architecture trade-offs. |
| [**Soil Reference Intervals**](soil-reference-intervals.md) | Soil Chemistry | Peer-reviewed reference intervals for pH, Electrical Conductivity (EC), Nitrogen, Phosphorus, and Potassium; laboratory analyte extractant sensitivities. |
