# Forecast model artifact

`soil_signal_gru.keras` and `soil_signal_gru_metadata.json` are generated by running from the repository root:

```powershell
.\services\zoning\.venv\Scripts\python.exe -m services.telemetry.train_forecaster
```

The script uses the pinned, locally bundled research data. The metadata records the chronological splits, scaler, architecture, feature units, per-horizon held-out metrics, and persistence-baseline comparison. Do not hand-edit metrics or treat a forecast as VWC or an irrigation command.
