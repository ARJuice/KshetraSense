📂 Datasets & Splits
PlantVillage — Primary training/evaluation dataset. 17 classes. Group-preserving train/val/test split via leaf_id. Audit and confirmed class map pending.
PlantDoc — Exploratory cross-dataset check only. Labels must be audited; only exact supported-class matches included. Coverage reported separately.
Synthetic soil grid — Fixed-seed 18×12, spatially coherent, seed #42. Not independently randomized per cell. No real farm data.
⚠ Known Limitations
  • • Soil field is purely synthetic — not sensor telemetry or field measurements.
  • • Crop compatibility shows only supported factors (pH, EC, Temp, N, P, K). Calcium, micronutrients, climate, drainage, and other FAO suitability factors are absent.
  • • Leaf classifier supports only 17 PlantVillage classes. Performance on field photos is not evaluated.
  • • Cluster IDs do not identify crops. FCM membership is not confidence or probability.
  • • No calibrated crop-success probability in this demo — requires outcome data and independent validation.
  • • Geographic area (acres/hectares) is not shown — the mock grid has no declared cell dimensions.
